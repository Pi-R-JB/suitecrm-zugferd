# suitecrm-zugferd
ZUGFeRD-Erweiterung für SuiteCRM AOS Invoices zur Erstellung EN-16931-konformer Rechnungen als PDF/A-3 mit eingebettetem Factur-X/ZUGFeRD-XML. Unterstützt Rechnungen, Stornorechnungen und Ersatzrechnungen sowie eine korrekte Umsatzbewertung von Stornierungen. Open Source und aktuell im Beta-Stadium.
